# Калькулятор рассрочки — PWA для риелторов

## Как запустить

1. Открой https://app.netlify.com/drop
2. Перетащи всю папку pwa_hastambu в окно
3. Получишь ссылку — открой на телефоне
4. Введи ключ: HASTAMBU-DEMO-2026
5. Браузер предложит «Добавить на главный экран»

## Как менять цены

1. Открой data.json
2. Измени pricePerSqm (сейчас 50000)
3. Измени version на текущую дату (например "2026-10-15")
4. Перетащи файл обратно в Netlify
5. Риелторы увидят баннер «Тарифы обновлены» при следующем открытии

## Как добавить ключ для риелтора

1. Открой keys.json
2. Добавь строку в массив keys:
   {"code": "REALTOR-NEW-003", "expires": "2027-01-01", "label": "1 год"}
3. Перетащи файл в Netlify
4. Отправь код риелтору

## Как включить пуш-уведомления

1. Зарегистрируйся на onesignal.com (бесплатно)
2. Создай Web Push приложение
3. Скопируй App ID
4. В index.html внизу раскомментируй блок OneSignal
5. Вставь свой App ID вместо YOUR-ONESIGNAL-APP-ID
6. Загрузи на Netlify
7. Для отправки пуша — зайди в панель OneSignal, нажми New Message
